# Non-Goals

TasviehYar is not trying to become a full back-office platform.

It will not store:
- pistachio type
- line items
- bag counts
- weights
- per-kilogram pricing
- inventory
- warehouse records
- freight calculations

It will not introduce:
- backend services
- cloud sync
- authentication providers
- payment gateways
- OCR
- voice entry
- messaging automation
- tax systems
- analytics dashboards
