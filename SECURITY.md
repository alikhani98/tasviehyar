# Security Policy

TasviehYar is a local-first financial application. Please report issues carefully and do not publish sensitive content in public tickets.

## Do not include

- customer information
- real financial records
- banking identifiers
- backup files
- screenshots that reveal sensitive information
- vulnerability examples based on real data

## Safe reporting

- Describe the issue with fictional or redacted examples only
- Avoid uploading exported files that contain personal or financial data
- Avoid sharing real phone numbers, card numbers, IBANs, or account numbers
- Avoid attaching local backup files or screenshots from a live pilot

## What to expect

Because this repository does not publish a security contact email, please use the public issue tracker with the safest possible redacted description.

If the issue is urgent and involves active sensitive data exposure, keep the details private until you can safely reduce the risk.
