# UX Principles

- Persian-first and RTL-first
- Large text and controls
- Low visual complexity
- Mobile-friendly spacing and layout
- Clear labels for elderly and technology-averse users
- No hidden or clever navigation
- Direct navigation should keep the main workflow visible without nested menus
- Warnings should be direct and readable
- Confirmation summaries should appear before saving financial records
- Money and date inputs should show clear previews without confusing the stored value
- History views should stay simple and readable rather than chart-heavy
- Development-stage limitations should be explicit
