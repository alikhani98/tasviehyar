# Pilot Checklist

Use this checklist when preparing or restarting a controlled pilot.

## Install
- Open the app in a modern browser.
- Confirm the app loads in RTL Persian layout.
- Confirm the install prompt or browser install option is available after the first visit.

## First Backup
- Open `پشتیبان‌گیری و بازیابی`.
- Download a fresh backup file.
- Save it in at least two safe places.
- Confirm the backup time appears in the pilot status panel.

## Test Data
- Create a test customer.
- Create one or two test recipients.
- Create their destination accounts.
- Keep the test records clearly named so they are easy to identify later.

## Test Invoice
- Create one small invoice for the test customer.
- Add one or two payment instructions.
- Confirm the invoice summary and instruction remainder look correct.

## Record a Payment
- Record a payment against the test invoice.
- Confirm the payment is shown in the payment list.
- Confirm the payment can be opened and reviewed.

## Check Balances
- Open the reconciliation view.
- Confirm the customer balance and recipient received amount are sensible.
- Compare the app totals with the paper notebook.

## Review Mismatches
- Open any mismatch cards.
- Confirm the navigation jumps to the related record.
- Resolve or note the mismatch before continuing.

## Restore Test Backup
- Download a fresh backup from the current data.
- Restore it into a separate empty browser profile or test database.
- Confirm the restored balances match the pre-backup balances.

## Parallel Operation
- Keep the paper notebook open while the pilot is active.
- Enter every important financial change in both places.
- Stop and investigate if the two records disagree.

## Discrepancy Reporting
- Record the issue in a simple note.
- Keep the original records unchanged until the discrepancy is understood.
- Tell the pilot owner before making corrections.

## Stop Criteria
- Stop pilot use immediately if totals disagree in a way that cannot be explained.
- Stop pilot use if a restore check does not match the backup.
- Stop pilot use if the notebook and app cannot be reconciled.
